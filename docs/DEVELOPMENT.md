# 开发与运维笔记

这份文档记录插件的架构、关键决策、踩过的坑和发布流程。写给未来的自己（以及任何想改这个仓库的人）。

---

## 一、项目结构

```
src/
  main.js       插件入口：生命周期、导航器面板管理、轮询、设置保存、更新检测
  smooth.js     冻结式缩放/拖动（"照片"机制）、快捷键、提交策略
  panel.js      导航小地图面板：DOM、手势、绘制调度
  renderer.js   小地图渲染（色块 / 折线 / 文字 / 图片）
  scene.js      元素 → 绘制项，含 versionNonce 缓存与点抽稀
  mapview.js    世界坐标 ↔ 面板坐标换算、缩放/平移
  geometry.js   屏幕坐标 ↔ 世界坐标（visibleSceneRect 等）
  settings.js   设置页（中英双语）与 DEFAULT_SETTINGS
tests/          53 个单测（几何、渲染、场景）
build.mjs       esbuild 打包
```

构建：`node build.mjs` → `main.js`（CJS，供 Obsidian 加载）。
需要带 Python 助手的旧版本：`node build.mjs --with-helper`（默认已剥离，避免社区审核问题）。

## 二、核心机制

### 1. 导航小地图

- **静态层 + 窗口裁切**：世界坐标渲染一张低清位图，面板按当前缩放/位置裁剪显示，平移时只改变裁切原点，不重绘；
- **元素缓存**：按 `versionNonce` 判断是否需要重建绘制项，避免每次全量遍历；
- **抽稀**：手绘按采样点数抽稀（默认 48），线段按屏幕像素阈值合并；
- **刷新节奏**：默认 250ms；主画布在动时自动提速到 60ms；
- **视口蓝框**：每 tick 用当前 `mapView` 重算，位置与缩略图同源。

### 2. 冻结式缩放/拖动

- 手势开始：把 Excalidraw 画布**原样拷一张位图**（照片），隐藏真实画布，挂一层与画布同尺寸的裁剪容器；
- 手势中：只对照片做 CSS `transform`（`matrix3d` 提升为合成层），不写 `appState`，所以 Excalidraw 不重绘；
- 停手：提交一次 `updateScene`，让它渲染一帧高清，然后撤掉照片；
- **底层低清底图**：手势超出照片范围时显示外围内容，避免纸色空白；
- **空闲预抓**：每 500ms 抓一张备用，且必须晚于上次提交才可用（否则会用旧缩放的照片 → 画面跳变）；
- **空白帧检测**：缩到 4×4 再采样（**不要**在大画布上 `getImageData`，GPU 回读很贵）。

### 3. 键盘

| 键 | 行为 |
| --- | --- |
| `Ctrl + =` / `-` / `0` | 缩放 / 复位，锚点按设置（居中或光标） |
| `Alt + 方向键` | 平移 60 屏幕像素，走冻结路径 |

`Ctrl±` 只要当前是 Excalidraw 视图就拦截，否则 Electron 会缩放整个界面。

## 三、关键参数

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 停手判定 | 120ms 起 | 缩得越小、元素越多会自动延长 |
| 照片长边上限 | 1600px | 超出等比缩小，降低合成压力 |
| 低分辨率阈值 | 缩放 < 35% | 抓帧用半分辨率 |
| 空闲抓帧间隔 | 500ms | 只在活动视图是 Excalidraw 时抓 |
| 小地图刷新 | 250ms / 移动时 60ms | |
| 世界低清底图 | 长边 ≤ 1500px | 按元素版本号缓存 |

## 四、踩过的坑（重要）

1. **不要对核心函数做逐行字符串替换**。开发过程中 `onWheel` 被改坏三次，分别误删了 `api`、`forceZoom`、以及 `api` 定义，导致滚轮完全失效却没有任何报错。→ **整段重写函数，改完 `node --check` + 真实操作验证。**
2. **静默 catch 会让故障隐身**。加了 `safe()` 失败计数后才定位到问题。任何 `catch {}` 附近都应能解释"吞掉的是什么"。
3. **画布 `visibility:hidden` 后，原生光标样式失效**（抓手变箭头）。→ 冻结时要把光标样式设在覆盖层上。
4. **Excalidraw 的 frame 名字是 DOM**（`div.frame-name`），不是画布内容；冻结时要一并隐藏。
5. **`offsetLeft/offsetTop` 属于屏幕偏移**，不能重复减到世界坐标里，否则左侧边栏一开，蓝框整体错位（错位量 = `offsetLeft / zoom`）。
6. **笔/鼠标事件差异**：数位板作为最近设备时，滚轮事件常丢失 `ctrlKey`。且光标不在画布上时，滚轮事件被 Obsidian 界面接收，**插件根本收不到**——这条是不可绕过的系统层限制，只能建议用户把滚轮设备映射成键盘按键。
7. **`saveSettingsAndSync()` 必须真的调用 `sync()`**，否则"关掉导航器"不会立刻消失（tick 兜底又会把它挂回来）。tick 里也要判断 `navigatorEnabled === false` 直接返回。
8. **多标签时 `view()` 要用"可见的" Excalidraw 叶子**，只用 `getMostRecentLeaf()` 可能缩放到另一个隐藏画布。
9. **切标签会重建 `appState`**，关闭 Show hint 要在 300ms 后补一次。
10. **合成事件自测会骗人**：用 `dispatchEvent` 造滚轮/指针事件，行为与真实输入不一致。调试要以真实操作为准。

## 五、性能数据（实测，4600+ 元素）

| 操作 | 开销 |
| --- | --- |
| 小地图平移跟随 | 0.01–0.02 ms/帧 |
| 小地图图层重建 | 7–10 ms |
| 冻结抓帧 | 1–3 ms |
| 手势中移动照片 | 一个 CSS transform ≈ 0 |
| 全量重绘 | 只在停手后发生一次（数十到数百 ms） |

剖析结论：手势期间主线程 78% 空闲，瓶颈在合成/栅格化，不在 JS。

## 六、放弃的方案（别再试）

| 方案 | 为什么放弃 |
| --- | --- |
| 动态延迟提交（按元素数分档） | 连续操作时反复提交，反而更卡 |
| 概览比例下不提交 | 与"随时能画"冲突，状态也会落后 |
| 自绘低清层替代真实画面 | 风格不一致、遮挡关系错、字体不对 |
| 拖动时平移真实画布 | 露白边，且与 Excalidraw 状态机打架 |
| Python 助手移动系统光标 | 社区审核不接受外部进程；笔尖会覆盖光标位置；已移除 |
| 画布外滚轮缩放 | 事件到不了页面，任何插件都做不到 |

## 七、发布流程

1. 改 `manifest.json` 的 `version`（三段式），同步 `src/settings.js` 里"关于"的版本号；
2. `node build.mjs`；
3. 复制到 `<vault>/.obsidian/plugins/excalidraw-canvas-optimizer/`；
4. `git commit && git push`（**push 需带代理**：`git -c http.proxy=http://127.0.0.1:9674 push`）；
5. `git tag -f <version> && git push -f origin <version>`；
6. `gh release create <version> main.js manifest.json styles.css --title ... --notes-file ...`；
7. 到 community.obsidian.md 的插件页点 **Check for new releases** 触发扫描。

注意事项：

- tag **不能带 `v` 前缀**，必须与 manifest 版本完全一致；
- release 里的 `manifest.json` 必须与仓库一致（否则审核报警告）；
- 仓库要保留 `package-lock.json`（构建可复现，审核会检查）；
- 插件名不得含 `obsidian`，且全仓库统一（manifest / 设置页 / README）；
- 描述以 `.` 结尾（审核规则）。

## 八、审核反馈对照（1.0.1 → 1.0.2）

| 警告 | 处理 |
| --- | --- |
| 插件名不一致 | 统一为 `Excali Canvas Optimizer` |
| 描述缺标点 | 补英文并以句号结尾 |
| release 与仓库 manifest 不一致 | 用同一份构建产物发布 |
| README 缺安装/使用说明 | 增加 Installation / Usage 章节 |
| README 无英文 | 全文双语 |
| 无 lockfile | 提交 `package-lock.json` |

1.0.2 审核结果：除"缺少构建来源证明"（可选建议）外全部通过，构建可字节级复现。

## 九、设置项语义

| 设置 | 含义 |
| --- | --- |
| 显示导航小地图 | 关掉即卸载面板、停止轮询 |
| 缩放锚点固定在画布中心 | 开=围绕中心缩放；关=跟随光标 |
| 顺滑缩放 | 关=Excalidraw 原生逐帧重绘 |
| 关闭画布提示 | 每次进入画布/切标签后自动关 |
| 停手判定 | 停手后多久渲染高清 |
| 小地图刷新间隔 | 采样主画布的频率 |
| 重置所有设置 | 恢复 DEFAULT_SETTINGS |
| 检测更新 | 比 GitHub 最新 release（唯一网络请求，用户手动触发） |
